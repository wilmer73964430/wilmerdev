# Neon Subs

Este repositorio contiene el código del sistema de suscripciones SaaS **Neon Subs**, implementado con Laravel 11, Tailwind CSS y una estética "verde futurista".

Toda la aplicación se encuentra dentro del directorio [`neon-subs/`](neon-subs/). Revisa su `README.md` para conocer los requisitos, la guía de instalación local y las instrucciones de despliegue en hosting compartido/cPanel.
